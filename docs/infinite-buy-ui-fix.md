# 무한매수 시트 UI 수정 작업 지시서

## 1. 작업 개요

이미 구현된 무한매수 시트(`app/infinite/page.tsx`)의 레이아웃을 수정한다.
"오늘 뭐 해야 하지?"가 바로 안 보이는 문제를 해결.

---

## 2. 현재 레이아웃 (문제)

```
1. 원금 대비 누적 수익
2. 사이클 현황
3. 오늘의 주문        ← 여기까지 스크롤해야 보임
4. 환전 내역 합산
```

**문제:** 핵심 액션(오늘 뭘 주문해야 하는지)이 중간에 묻혀서 눈에 안 띔.

---

## 3. 변경 후 레이아웃

```
1. 🔔 오늘의 할 일    ← 최상단, 강조
2. 사이클 현황
3. 원금 대비 누적 수익
4. 환전 내역 합산
```

---

## 4. "오늘의 할 일" 섹션 수정

### 4-1. 위치
기존 "오늘의 주문" 섹션을 **페이지 최상단**(툴바 바로 아래)으로 이동.

### 4-2. 스타일 강조

- **섹션 헤더**: 배경 `#F9A825` (진한 노랑), 흰색 텍스트, 볼드
  - 기존 초록/파랑 헤더와 차별화하여 시선 집중
- **섹션 바디**: 배경 `#FFFDE7` (연한 노랑)
- **현재가/평단가 비교**: font-size 14px, 볼드
- **매수 테이블**: 주문가/수량 파랑(`#1565C0`) 볼드
- **매도 테이블**: 목표가/수량 초록(`#006100`) 볼드
- **하단 안내 문구**: 빨강(`#C62828`) 볼드

### 4-3. 헤더 텍스트

변경 전: `오늘의 주문 — 현재가 $58.59 > 평단가 $56.43`
변경 후: `🔔 오늘의 할 일`

현재가/평단가 비교는 바디 첫 줄에 큰 글씨로 표시.

### 4-4. 바디 구조

```
── 🔔 오늘의 할 일 ──────────────────────────── (노랑 배경)

현재가: $58.59  |  평단가: $56.43  |  현재가 > 평단가   ← 14px 볼드

판단: 1칸($67.58) ÷ 현재가($58.59) = 1주 → 2주 미만 → 확보용 LOC 1주

LOC 매수:
| 구분       | 주문가  | 수량 | 금액   | 설명                   |
| 확보용 LOC | $64.89 | 1주  | $64.89 | 평단가 × 1.15          |

예약 매도:
| 구분     | 목표가  | 수량 | 예상금액 | 설명              |
| 전량익절 | $62.07 | 1주  | $62.07  | 평단가 × 1.10 전량 |

→ 한투앱에서 LOC $64.89 × 1주 매수 + 예약매도 $62.07 × 1주 설정   ← 빨강 볼드
```

### 4-5. 현재가 < 평단가일 때

```
현재가: $54.20  |  평단가: $56.43  |  현재가 < 평단가

판단: 1칸($67.58) ÷ 현재가($54.20) = 1주 → 현재가 LOC 1주

LOC 매수:
| 구분       | 주문가  | 수량 | 금액   | 설명          |
| 현재가 LOC | $54.20 | 1주  | $54.20 | 평단가 낮추기  |

예약 매도:
| 구분     | 목표가  | 수량 | 예상금액 | 설명              |
| 전량익절 | $62.07 | 1주  | $62.07  | 평단가 × 1.10 전량 |

→ 한투앱에서 LOC $54.20 × 1주 매수 + 예약매도 $62.07 × 1주 설정   ← 빨강 볼드
```

## 5. 나머지 섹션 순서 변경

기존 코드에서 섹션 렌더링 순서만 변경:

```tsx
return (
  <>
    {/* 1. 오늘의 할 일 — 최상단 */}
    <TodayAction />
    
    {/* 2. 사이클 현황 — 기존 그대로 */}
    <CycleStatus />
    
    {/* 3. 원금 대비 누적 수익 — 기존 그대로 */}
    <CumulativeProfit />
    
    {/* 4. 환전 내역 합산 — 기존 그대로 */}
    <ExchangeHistory />
  </>
);
```

각 섹션의 내부 내용은 변경 없음. 순서만 바꿈.
